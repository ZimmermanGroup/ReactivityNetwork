# Data

This folder includes the raw data generated and used in this project.  
Preprocessing of this data can be found in `src/dataset.py`
Another component are the excel and gephi files used in the visualization of the networks in the paper.

1. **final_report.csv**

   These csv files include the raw data. Each row shows chemicals and their amounts added to each well.  
   Column "**suzuki_product_CAD_yield**" has the yield values determined for each reaction.  
   As mentioned in the Supporting Information, yields of crude reaction mixtures were assessed with a charged aerosol detector (CAD) coupled to HPLC.  
   The corrected CAD yield was calculated using a [previously published method](https://pubs.acs.org/doi/full/10.1021/acs.jmedchem.3c02029).  
   Note that some of the reported yields are above 100%. These are attributed to variations in dispenses of the internal caffeine standard and/or precipitation of reagents during plating which resulted in variability in the limiting reagent, or droplet carry over.

2. **preliminary folder**

   This folder includes csv files that are formatted in a similar manner, but are from preliminary screening as we were exploring reaction conditions.  
   Column "**suzuki_product_0__Estimated_%conversion**" includes values used as yields from these high-throughput experiments.  
   Analyses of these preliminary data can be found in `src/dataset_analysis.ipynb`.  
   Detailed description is provided in section 4.1 in the Supporting Information, pages S6~S8.  

3. **gephi_files folder**

   This folder includes excel and gephi files used to visualize the networks presented in figures throughout this manuscript.  
   The excel files `suzuki_nodes_full.xlsx` and `suzuki_edges_full.xlsx` can be generated by running the following snippet in a jupyter notebook: 
   ```python
   from dataset import *
   from rmap import *
   entire_rmap = ReactivityMap(source_core_inds=None, target_core_ind=-1, test_bb_inds=[], dataset=suzuki_data)
   entire_rmap.get_similarity_matrix(gephi_filename="full")
   ```  
   The Tanimoto similarity edges can be obtained by specifying `tanimoto=True` in `.get_similarity_matrix()` method.  
   Similarly, `first_selection.xlsx` files, which lead to Figure 5D, can be generated by running:
   ```python
   core4_rmap = ReactivityMap(source_core_inds=None, target_core_ind=3, test_bb_inds=[], dataset=suzuki_data)
   core4_rmap.get_similarity_matrix(gephi_filename="first_selection")
   ```

   Please refer to pages S13~S18 in the Supporting Information for a detailed procedure of how to use gephi starting from the excel files.  
   For people who would like to directly look at the network as presented in the paper, the `.gephi` files are provided as is. The similarity threshold will need to be applied.  
   Also note that the layout algorithm is not deterministic and may lead to a form different from what is presented in our work.  
   **_Generates Figures 3B–3C_**
   

4. **descriptors.csv**

   These csv files include the 10 descriptors used for aryl halides (cores) and boronic acids / pinacol esters (BBs).  
   In addition, the "Centroid" and "Cluster" columns in the boronic_descriptors.csv show the results from the initial Butina clustering.  
   Values under the "Cluster" column show the cluster number (in descending order of cluster size) the BB was a member of.  
   For the "Centroid" column, values that are NOT -1 denote the corresponding BB was a centroid.  
   Please understand that the raw Butina clustering analysis cannot be made public due to the list of initial compounds being proprietary data.  
    * highest occupied molecular orbital (HOMO) energy
    * lowest unoccupied molecular orbital (LUMO) energy
    * dipole moment
    * natural bond orbital of the reacting group’s central atom (B for BBs and Br for cores)
    * natural bond orbital of the ipso carbon
    * %buried volume at the reacting group central atom
    * Sterimol L, B1 and B5 with the reacting group central atom as the axis
    * bond length of C–reacting group central atom

5. smiles_to_cluster_dict.joblib

   A dictionary between BB SMILES and the cluster number for convenience in processing data.
